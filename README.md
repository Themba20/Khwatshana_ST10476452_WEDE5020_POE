## Project Overview
Mswenko Home & Lifestyle Store is a fictional South African retail organisation for the web-development Portfolio of Evidence. The website serves customers in Pretoria and Johannesburg.

## Website Goals and Objectives
1. Increase online awareness.
2. Present products clearly.
3. Generate customer enquiries.
4. Make branch information easy to find.
5. Provide consistent and accessible navigation.

## KPIs
- Monthly website visits.
- Product-page views.
- Enquiry submissions.
- Contact-page visits.
- Call-to-action engagement.

## Key Features
- Five linked HTML pages.
- Shared navigation.
- Semantic HTML.
- Product categories.
- Enquiry form.
- Two branch locations.
- Responsive CSS.
- Original SVG assets.
