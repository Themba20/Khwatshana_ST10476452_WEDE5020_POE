# Part 1 Implementation Guide

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a browser or local development server.
3. Test navigation from every page.
4. Check image paths and form labels.
5. Resize the browser to desktop, tablet and mobile widths.
6. Test in at least two browsers.
7. Create the private GitHub repository required by the lecturer.
8. Commit changes using the descriptive messages in README.md.
9. Replace every `[INSERT ...]` placeholder with your real student information.
10. Update the timeline dates to match the official subject submission dates.
11. Confirm lecturer approval before final submission.
