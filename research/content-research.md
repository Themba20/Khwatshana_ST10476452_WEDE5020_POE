# Content Research and Sourcing

## Organisation
Mswenko Home & Lifestyle Store is a fictional organisation created for the academic project. Its history, mission, vision, locations and product descriptions are original project content.

## Web structure research
Semantic HTML elements such as `header`, `nav`, `main` and `footer` provide meaningful page regions that can assist users of assistive technologies (W3C, 2026). Responsive design is included because users access websites on different screen sizes (web.dev, 2020).

## Content sources
- Organisation content: original content created for the fictional client.
- Wireframe: supplied by the student and stored in `docs/wireframe.png`.
- Logo and illustrations: original SVG assets created for this project.
- Future third-party image option: Unsplash, subject to its licence and other rights considerations.

## Legal asset sourcing
The current website avoids third-party photographs by using original SVG illustrations. If third-party images are added later, the source, creator where available, licence, URL and access date must be recorded. Unsplash notes that identifiable people, property and trademarks can involve additional rights (Unsplash, 2025/2026).
